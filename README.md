# Quackmire

A 3D browser survival game. You are a mother duck raising ducklings: find food, cross the roads, fend off predators, and get home before dark. Each day is harder than the last, so see how long you can survive.

The game is a single page, `index.html`. It loads Three.js and its fonts from public CDNs, so there is no build step.

## Playing

Works in current browsers on phones, tablets and computers, with touch, keyboard and mouse, or a gamepad. It can be installed to a home screen and opens offline after the first visit. The graphics lower automatically on slower devices.
